# 🏠 House Price Prediction using Multiple Linear Regression

This project demonstrates the implementation of **Multiple Linear Regression** to predict house prices using multiple property features such as area, bedrooms, bathrooms, parking spaces, furnishing status, and other amenities.

---

## 📌 Objective

To build a Multiple Linear Regression model that accurately predicts house prices based on multiple independent variables and understand the complete machine learning workflow.

---

## 📊 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains **545 house records** with **13 features** including:

- Area
- Bedrooms
- Bathrooms
- Stories
- Main Road
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking
- Preferred Area
- Furnishing Status

Target Variable:

- Price

---

## 📈 Project Workflow

- Import Libraries
- Load Dataset
- Exploratory Data Analysis
- Data Visualization
- Data Preprocessing
- Feature Encoding
- Correlation Analysis
- Train-Test Split
- Model Training
- Prediction
- Model Evaluation
- Residual Analysis
- Conclusion

---

## 📌 Results

The Multiple Linear Regression model successfully learned the relationship between multiple house features and the selling price. The project demonstrates preprocessing of categorical variables, model training, prediction, and evaluation using standard regression metrics.
