# 💰 Salary Prediction using Simple Linear Regression

This project demonstrates the implementation of **Simple Linear Regression** to predict employee salaries based on years of experience.

## 📌 Objective

To understand how a regression model learns the relationship between **Years of Experience** and **Salary** and predicts salaries for new employees.

## 📊 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset

- Feature: YearsExperience
- Target: Salary

## 📈 Workflow

- Import Libraries
- Load Dataset
- Exploratory Data Analysis
- Data Visualization
- Train-Test Split
- Train Linear Regression Model
- Prediction
- Model Evaluation
- Regression Line Visualization

## 📌 Results

The model successfully predicts salaries based on years of experience and demonstrates the complete workflow of a Simple Linear Regression model.
